| W-D005 (amended) | Sourced-field citations (rulings 3 and 4 on #15, W-S3 day one) | A fact line of content/owner-facts.md starts at column 0 with `- **TO CONFIRM:**` or `- **CONFIRMED`. Headings, intro bullets, nested items, continuation lines and bullets with another bold run (`- **DROPPED:**`) are never fact lines. A cited fact line carries one id tag `{#<id>}` (kebab-case) on that line, by convention right after its marker; the position is not checked. On a placeholder:true entry of any class, source is '' or `<path>=<id>` pairs joined by '; '. The path is relative to the entry, as the validator names it: kind, url, demo, cover, links[i].href, media[i].src, media[i].poster and media[i].captions for projects; kind, metal, photo and project for honours; status, still, credit.mode and credit.museumUrl for worlds; email and links[i].href for the profile. A non-empty enum, link or asset value passes only when its path has a pair whose id tags exactly one fact line, at any status, TO CONFIRM included. Each failure is one error naming the path: a value with no pair; an id on no fact line or on several (naming the id); a path listed twice. Display text stays tokens, and confirmed entries keep free-text sources.
