# 3D sources (W-C13)

Everything the site's real 3D is built from. Nothing here ships; `public/models/` does.

| Path | What it is |
|---|---|
| `camera_xt/build_camera.py` | The camera, built in Blender 5.0 from one script: LOD0 (full tier), LOD1 (lite tier), the Manor LOD |
| `camera_xt/export/*.glb` | Blender's raw exports, the input of the optimizer (kept so the shipped GLBs can be re-derived without Blender) |
| `camera_xt/rig.json` | The rig contract (W-D019): pivots, markers, materials, verbs, and each node's original transform. Generated |

## Rebuild

```powershell
powershell -File scripts/build/glb/build.ps1               # Blender (blender lane, GPU only) -> optimize -> rig -> glbstat
powershell -File scripts/build/glb/build.ps1 -SkipBlender  # from the committed raw exports, no Blender
node scripts/build/glb/optimize.mjs --check                 # shipped GLBs = a fresh optimize of the raw exports
node --test "tests/w-c13/**/*.test.mjs"                     # the rig in three r186, budgets, no .blend
```

- The `.blend` is saved outside the repos (`portfolio-assets/xt5/blend/`); reference images live in
  `portfolio-assets/xt5/refs/`. Neither is ever committed.
- Blender always runs `scripts/fork/blender_gpu.py` first (D-012). Set `ION_BLENDER_GPU` if the fork lives elsewhere.

## The rig (W-D019)

glTF axes: +Y up, the lens looks down +Z, +X is the camera's own left. Units are metres.

- **Pivots** (empties; each carries its part as a `<pivot>_mesh` child): `dial_shutter`, `dial_ev`, `dial_look`
  (5 detents, 30 degrees apart), `shutter_button` (1.2 mm travel down -Y), `lens`, and `lens_aperture_ring` and
  `lens_focus_ring` as children of `lens` (both spin about +Z).
- **Markers** (empties): `print_exit`, `lens_mount`, `strap_left`, `strap_right`.
- **Materials**: `cam_silver`, `cam_black_metal`, `cam_leather`, `cam_rubber`, `cam_amber`, `cam_glass`, `cam_paint`
  (index ticks), `cam_lettering` (engravings; the FUJIFILM and X-T5 marks join it in m2). The Manor LOD uses the
  flat slots `mat_silver`, `mat_graphite`, `mat_glass_dark`, `mat_brass` and keeps only `shutter_button` and `lens`.

Swapping LODs never moves a pivot or a marker: `rig.mjs` fails the build if any LOD disagrees.

## Milestones

- **m1 (this):** the Wave 1b evidence camera, re-optimized with the pivot-safe flags. Against the evidence script it
  drops the `[ ]` badge from the body (D-011), adds `strap_left`/`strap_right` and `cam_lettering`, and gives LOD1
  the engravings and ticks so both web LODs carry all eight materials.
- **m2:** the 1:1 X-T5 rebuild from cited references (D-011, D-014, D-015, D-021), with the decal nodes
  `mark_fujifilm` and `mark_xt5` and the strap with `strap_tag`.
